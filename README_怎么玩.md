# Xiaoju Word — Traditional Architecture 0.16.0-open.1

完整解压，双击 `Start.cmd` 或 `XiaojuWorld.exe`。EXE、PCK 与许可文件保留在同一目录。离线运行，无需安装开发工具。默认 Direct3D 12，可使用 `Start-Vulkan.cmd` 尝试 Vulkan。

WASD 移动，Shift 跑步，空格跳跃。E 使用服务，F 采集或上下交通工具，X 坐卧，按方向键起身。B 背包，G 布置，R 旋转，F 确认，Esc 取消。M 地图，N 小地图，O 斜俯视，V 观察，Home 全图，P 拍照，F12 保存照片，F5 保存旅行，F6 昼夜天气。

建议从七层城郭、朱柱廊道、生活小院开始，再前往东北浮空景观。高层宫阙主要供观赏；下层步桥和亭台可到达。场馆媒体均为原创演示内容。

公开版存档位于 `%APPDATA%/Godot/app_userdata/Xiaoju Word - Traditional Architecture/save/open_traditional_v1`。独立于私人版和旧公开版。个人导入库在程序旁的 `UserMedia`，默认下载包不含任何个人素材。
